## 1. Executive Summary & Monorepo Architecture

The CWP Detailers Staff application is deployed as a hybrid application:
1. **Frontend Web Shell / PWA**: Located in `artifacts/cwp-platform/src`, using React 19, Vite, TanStack Query, and Wouter.
2. **Android Capacitor Shell**: Located in `artifacts/cwp-staff-app`, wrapping `@workspace/cwp-platform` with native Android capabilities (`@capacitor/camera`, `@capacitor/geolocation`, `@capacitor-community/background-geolocation`, and custom Java plugin `NativeLocationBridgePlugin.java`).
3. **Backend API**: Located in `artifacts/api-server/src`, Express 5 REST API backed by PostgreSQL and Drizzle ORM.
4. **Database Models**: Located in `lib/db/src/schema`, including `dcms.ts`, `staff.ts`, `staff-ecosystem.ts`, `service-executions.ts`, `attendance.ts`, and `push-notifications.ts`.

## 3. Existing Supporting Components & Services Inventory

1. **StaffJobAlertLayer & StaffJobAlertPopup**:
   - Location: `artifacts/cwp-platform/src/components/staff/StaffJobAlertLayer.tsx`
   - Behavior: 30-second polling of `/api/bookings/today` and `/api/service-executions/today`.
   - Native sound & vibration triggers on new unacknowledged jobs.
   - Issue: "Open Today" button redirected to `/staff/dashboard` rather than `/staff/bookings?job=...`.
2. **StaffVehicleCleanDialog**:
   - Location: `artifacts/cwp-platform/src/features/daily-cleaning/components/StaffVehicleCleanDialog.tsx`
   - Handles photo capture, OCR verification, manual registration fallback, and completion mutation.
   - Gap: Location was captured on submit instead of photo snap; technical UI jargon shown to field staff.
3. **StaffExecutionActionsSheet**:
   - Location: `artifacts/cwp-platform/src/features/daily-cleaning/components/StaffExecutionActionsSheet.tsx`
   - Handles operational exceptions (`car_not_available`, `plate_not_visible`, `customer_skip`, `access_denied`, `issue_reported`).
4. **Offline Resilience Store**:
   - Location: `artifacts/cwp-platform/src/features/daily-cleaning/lib/dcmsLocalStorage.ts`
   - Scoped by `staffId` and IST calendar date (`YYYY-MM-DD`).
   - Automatically merges with server route stops on fetch failure or intermittent connectivity.
5. **Location Subsystem**:
   - `artifacts/cwp-platform/src/lib/location/LocationProvider.tsx`: Persistent provider mounted in `StaffLayout`.
   - `NativeLocationBridgePlugin.java`: Android native plugin for checking location provider status, requesting runtime permissions, and resolving location settings dialog.
   - `artifacts/api-server/src/lib/dcms/visitService.ts`: Validates geofence radius (default 250m) against assigned subscription location, handles B1/B2/B3 basement parking GPS fallback, watermarks photo, and commits audit record.
