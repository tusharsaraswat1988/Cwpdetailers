## 3. Component Standardization & Consolidation Matrix

| Component Area | Legacy Implementation | Standardized Design System Implementation | Affected Surfaces | Benefits Delivered |
| :--- | :--- | :--- | :--- | :--- |
| **Status Badges** | Raw `span` tags with fragmented colors and Lucide icons; occasional color-only indicators | Canonical `<StatusBadge />` & `<CwpStatusBadge />` pairing high-contrast accessible color, explicit text label, and official Material Design 3 Symbol (`check_circle`, `schedule`, `sync`, `warning`, `cancel`) | Monorepo-wide (Admin, Staff, Customer, Franchisee) | Full WCAG 2.2 AA non-color-only compliance; unified optical weight. |
| **Buttons & Action Hierarchy** | Varied button heights (32px to 40px on mobile); inconsistent focus rings (`ring-1`) | Standard `<Button />` with `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2`; role-adapted wrappers (`AdminButton`: 36px, `CustomerButton`: 48px, `StaffButton`: 52px) | All input forms, modals, tables, and toolbars | Clear visible focus indicators for keyboard navigation; zero missed taps for field staff. |
| **Form Inputs & Textareas** | Sub-pixel border inconsistencies; weak focus outline (`ring-1 ring-ring`) | Standard `<Input />`, `<Textarea />`, and `<Select />` with WCAG 2.2 AA compliant `focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2` | 48+ input forms across all applications | High contrast focus states; full keyboard operability. |
| **Dialogs & Overlays** | Long modal viewport clipping on laptops (1366×768) where Save/Submit buttons fell below screen | Hardened `<DialogContent />` and `<AlertDialogContent />` with `max-h-[90vh] overflow-y-auto` base styles | 38+ dialogs and confirmation modals | 100% elimination of viewport button clipping; accessible scrolling. |
| **Empty States** | 8 different ad-hoc dashed container implementations with unguided hints | Unified `<EmptyState />` with 48px M3 Symbol, encouraging headline, concise explanation, and primary CTA | Directories, asset lists, queues, history | Guided user recovery; zero dead-ends in customer booking or admin lists. |
| **Financial & Table Density** | Uneven left/right currency alignment; proportional numbers causing jagged columns | Strict right-alignment (`text-right font-mono tabular-nums`) in `DataTable.tsx`, `PaymentLedgerPage.tsx`, `PaymentsTab.tsx`, `DuesTab.tsx`, `ExpensesTab.tsx`, `QuotationsTab.tsx` | Billing, ledgers, dues, invoices, analytics | Scannable, professional financial statements with perfectly aligned decimal columns. |
| **Iconography Standard** | Mixed Lucide, custom SVG, and unicode emojis (`🏢`, `☀️`, `🚗`, `⚡`, `🧹`, `⚠`) used as interface icons | Google Material Design 3 Material Symbols Outlined standard via `<MaterialSymbol />`; 0 emoji as UI icons | Navigation bars, badge pills, job lists, metric cards | Clean, professional enterprise finish; unified stroke weight (400 regular, 500 semibold). |
| **Root Design Tokens** | Root `:root` in `index.css` had dark mode primary/ring defaulting to legacy teal (`180 100% 45%`) | Aligned `:root` and `.dark` with canonical CWP Electric Blue (`#1677FF`, `215 100% 54%` light, `215 100% 60%` dark) | Portaled dialogs, toasts, overlays | Zero jarring color flashes when dialogs portal to `document.body`. |
